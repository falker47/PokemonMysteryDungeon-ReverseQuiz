# PMD Reverse Quiz — app

React/Vite frontend for the PMD Reverse Quiz project.

See the [repository README](../README.md) for supported games, accuracy notes, data sources, and product-level documentation.

## Development

```bash
npm install
npm run dev
```

Run the full local verification suite with:

```bash
npm run check
```

That command runs ESLint, validates the quiz datasets, and creates a production build.
